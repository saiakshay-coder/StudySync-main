Slide 12 - Docker Usage (Actual Command and Workflow)
Page Text:
- Compose file location: project root `compose.yaml`.
- Start all DB services:
  - `docker compose -f "compose.yaml" up -d`
- Stop services:
  - `docker compose -f "compose.yaml" down`
- Reset DB volumes (fresh data state):
  - `docker compose -f "compose.yaml" down -v`
- Recommended practice:
  - keep app servers local (`npm run dev`, `npm run chat`) while DB services run in containers.
